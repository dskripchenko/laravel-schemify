# Начало работы

`dskripchenko/laravel-schemify` даёт Laravel-приложению динамические
PostgreSQL-соединения в разрезе *слоёв*. **Слой** — это именованная схема
(опционально на собственном соединении с базой данных); Schemify по запросу
переключает активное соединение на эту схему и обучает команды миграций опции
`--layer`.

## Требования

- PHP 8.2–8.5
- Laravel 11 / 12 / 13
- PostgreSQL
- Заданный `APP_KEY` (учётные данные БД хранятся в зашифрованном виде)

## Установка

```bash
composer require dskripchenko/laravel-schemify
php artisan layers:install
```

Сервис-провайдер обнаруживается автоматически. `layers:install` идемпотентна и:

1. публикует `config/schemify.php` и базовую миграцию,
2. мигрирует **центральный** слой (создавая таблицы `db_connections` и
   `layer_items`),
3. регистрирует слой `main` по умолчанию.

Добавьте `--force`, чтобы перезаписать опубликованные файлы и пропустить
подтверждения (полезно в CI / при деплое):

```bash
php artisan layers:install --force
```

## Основные концепции

### Слои

Каждый слой — это строка в `layer_items`:

| столбец | значение |
|---|---|
| `name` | уникальное имя слоя (используется с `--layer`) |
| `schema_name` | PostgreSQL-схема, на которую он отображается |
| `layer` | тег группы/типа (позволяет `getAllLayerItems($type)` получить набор) |
| `db_connection_id` | строка `db_connections`, на которой он размещён |

Строка `db_connections` хранит драйвер/хост/порт/базу/имя пользователя/пароль
сервера, на котором находится схема, — так что разные слои могут указывать на
совершенно разные базы данных.

### Центральный и тенантные слои

- **Центральный слой** (`schemify.central_layer`, по умолчанию `core`)
  работает против соединения приложения по умолчанию **без** переключения
  схемы. Его миграции находятся в `database/migrations`. Здесь же располагаются
  собственные таблицы пакета.
- **Тенантные слои** — это именованные схемы. Единый общий набор тенантных
  миграций выполняется против каждого из них — см. [Миграции](migrations.md).

## Конфигурация

`config/schemify.php` (публикуется командой `layers:install`):

```php
return [
    'connection'    => env('DB_LAYER_CONNECTION', 'layer'),
    'central_layer' => env('SCHEMIFY_CENTRAL_LAYER', 'core'),
    'migrations'    => [
        'path'         => database_path('migrations/tenant'),
        'central_path' => database_path('migrations'),
    ],
];
```

Шаблон соединения `layer` и иерархия `layersStruct` находятся в
`config/database.php` (добавляются пакетом при слиянии). `layersStruct` — это
вложенная карта включённых слоёв, используемая командой `layers:migrate`:

```php
'layersStruct' => [
    'core' => [
        'main' => true,
    ],
],
```
